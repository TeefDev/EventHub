# EventHub 🎉

EventHub is an event management and booking platform developed using ASP.NET Web Forms and SQL Server.

## Features
- User Registration & Login
- Browse Events
- Event Booking System
- My Bookings Page
- Contact Us Form
- Admin Dashboard
- Event Management (CRUD)
- Booking Management
- Email Notifications
- SQL Server Database Integration

## Technologies Used
- ASP.NET Web Forms
- C#
- SQL Server
- HTML
- CSS
- JavaScript
- Bootstrap
